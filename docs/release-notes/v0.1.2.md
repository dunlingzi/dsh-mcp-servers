## 中文

### 新功能

- **设置页「MCP 服务器」管理面**：新增/编辑/启停/删除服务器，支持 stdio 与
  streamable-http 两种传输的表单，以及粘贴 `mcpServers` JSON 导入；服务器按状态分级展示
  （运行中 / 连接中 / 未连接 / 失败），支持单次探活。
- **模型面双轨**：已连接的服务器，其工具以 `mcp__<server>__<tool>` 注册给模型直接调用；
  项目级服务器默认经中间层 `ws_mcp_*` 四原子工具收敛模型面（`ws_mcp_list` /
  `ws_mcp_detail` / `ws_mcp_search` / `ws_mcp_call`），只读三件不触达远端。
- **设置页信息架构与可访问性**：列表/编辑页重排，补全键盘可达与双语字典；客户端路由表改为
  消费构建期注入的 `__DSH_ROUTES__`（路由单一事实源，不再手写副本）。

### 改进

- **宿主兼容窗口扩到已发布宿主的全集**：本版声明的宿主兼容窗口自 `0.1.5-rc.2` 起向上覆盖
  （floor = 已实机验证的最低宿主），已发布宿主全部放行，不再出现「宿主升级后本插件被静默
  跳过不加载、并从 profile 的 `dsh.profile.bundles` 写掉」的情形。代价是窗口内未实测宿主
  不保证运行时 API 兼容——宿主发布新里程碑或有破坏性 API 变更时重评 floor。
- **中间层与连接仲裁的结构拆分**（对外行为零变更，导出面快照零 diff）：`manager.ts`
  1113 → 766 行、`middleware-register.ts` 730 → 171 行，拆出探活 / 投影 / 双轨桥接 /
  收敛 / 工具工厂等模块；同批消除 3 处门面取值回边，文件级值环 4 → 1。
- **门禁与证据面**：重建导出面快照门禁（重构的零行为变更证据）、路由表一致性判据、
  依赖门禁尺子修正（文件拆分不再被误判为回归）、文档面收口。

### 修复

- 修 CI `changes` 作业缺 `pull-requests: read` 导致的 PR 路径预筛 fail-closed 死锁。
- 修 `gen-stryker-conf` 行尾敏感比对在 Windows 检出下必然判红。
- 修 `POST /servers` 把 `body.cwd` 当成会话 cwd（#1）：会话 cwd 只从 query 取，
  `body.cwd` 回归「服务器工作目录」语义。

### 兼容性

- **宿主（dsh）**：兼容窗口自 `0.1.5-rc.2` 起向上覆盖（`>=0.1.5-rc.2`；floor = 已实机
  验证的最低宿主，低于 floor 的宿主不在声明范围内）。已实机验证：0.1.5-rc.2 / 0.1.5-rc.3 /
  0.1.6-alpha.1 / 0.1.6-alpha.2 / 0.1.7-alpha.1 / 0.1.7-alpha.2 / 0.1.7-rc.1 / 0.1.7-rc.2 /
  0.2.0-rc.1 / 0.2.0-rc.2 / 0.2.1-alpha.1 全部通过。判定用宿主自己的
  `evaluatePluginCompatibility`，非推演。
- **`@deepseek-ai/cordis`**：`4.0.2 || 4.0.4`（cordis 版本体系独立，不随 dsh 的 rc 节奏走）。
- **Node**：`>=20.0.0`。
- 与 `@wingsky-1/dsh-mcp-manager` **互斥安装**（共享 `<DSH_HOME>/dsh-mcp.json` 与
  `ws_mcp_*` / `mcp__` 工具面，同装双注册冲突）。
- 数据与安全：全部 HTTP 路由强制 loopback 围栏（非回环 403、方法错 405），唯一例外是
  只读 `GET /config`；服务器配置落盘 `0600` 且原子写；stdio 子进程 env 先剔除
  `(KEY|TOKEN|SECRET|PASSWORD|PASSWD|CREDENTIAL|AUTH)` 形状变量与 `DSH_*` 前缀。

### 安装

```sh
dsh plugin --profile web add @dunlingzi/dsh-mcp-servers
```

装后重启一次 `dsh web`。

## English

### Features

- **Settings page for MCP server management**: add / edit / enable / disable / delete servers,
  stdio and streamable-http form support, paste-in `mcpServers` JSON import, status-bucketed
  listing (running / connecting / disconnected / failed) and one-shot probing.
- **Dual-track model surface**: tools of connected servers are registered as
  `mcp__<server>__<tool>` for direct model calls, while project-scoped servers default to the
  middleware four-tool surface (`ws_mcp_list` / `ws_mcp_detail` / `ws_mcp_search` /
  `ws_mcp_call`); the three read-only tools never touch the remote.
- **Settings page information architecture and accessibility**: reworked list/edit views,
  keyboard reachability and bilingual dictionaries; the client route table now consumes the
  build-time injected `__DSH_ROUTES__` instead of a hand-written copy.

### Improvements

- **Host compatibility window widened to the full set of published hosts**: this release declares
  host compatibility from `0.1.5-rc.2` upwards (the floor is the lowest host verified on a real
  machine), so every published host is admitted and the plugin is no longer **silently skipped**
  and dropped from `dsh.profile.bundles` on a host upgrade. In exchange, unverified hosts inside
  the window carry no runtime API guarantee, so the floor is re-evaluated when the host ships a
  new milestone or a breaking API change.
- **Structural split of the connection arbiter and middleware layer** (zero behavior change,
  export-surface snapshot diff is empty): `manager.ts` 1113 → 766 lines,
  `middleware-register.ts` 730 → 171 lines; three facade value back-edges removed, file-level
  value cycles 4 → 1.
- **Gate and evidence surface**: rebuilt export-surface snapshot gate (proof of zero behavior
  change for refactors), route-table consistency criterion, dependency-gate ruler fix (file
  splits are no longer misread as regressions), documentation consolidation.

### Fixes

- Fixed a fail-closed deadlock in the CI `changes` job caused by a missing
  `pull-requests: read` permission.
- Fixed a line-ending sensitive comparison in `gen-stryker-conf` that always failed on
  Windows checkouts.
- Fixed `POST /servers` treating `body.cwd` as the session cwd (#1): the session cwd now comes
  only from the query, and `body.cwd` keeps its "server working directory" meaning.

### Compatibility

- **Host (dsh)**: the compatibility window covers `0.1.5-rc.2` and above (`>=0.1.5-rc.2`; the
  floor is the lowest host verified on a real machine, and hosts below it are outside the
  declared range). Verified on a real machine: 0.1.5-rc.2, 0.1.5-rc.3, 0.1.6-alpha.1,
  0.1.6-alpha.2, 0.1.7-alpha.1, 0.1.7-alpha.2, 0.1.7-rc.1, 0.1.7-rc.2, 0.2.0-rc.1, 0.2.0-rc.2
  and 0.2.1-alpha.1. The verdict comes from the host's own `evaluatePluginCompatibility`, not
  from reasoning.
- **`@deepseek-ai/cordis`**: `4.0.2 || 4.0.4` (cordis has an independent version line).
- **Node**: `>=20.0.0`.
- Mutually exclusive with `@wingsky-1/dsh-mcp-manager` (shared `<DSH_HOME>/dsh-mcp.json` and
  the `ws_mcp_*` / `mcp__` tool surface).
- Data and security: every HTTP route enforces a loopback fence (403 for non-loopback, 405 for
  wrong method) except the read-only `GET /config`; server config is written atomically with
  mode `0600`; stdio child processes get an environment with `(KEY|TOKEN|SECRET|PASSWORD|
  PASSWD|CREDENTIAL|AUTH)`-shaped variables and the `DSH_*` prefix stripped first.

### Install

```sh
dsh plugin --profile web add @dunlingzi/dsh-mcp-servers
```

Restart `dsh web` once after installing.
